One tap to save riders in Contacts

Remap Tour is a web app, and Android only lets real apps open Contacts' Create contact. Install the small Remap Contacts app once on this phone (95 KB). After that the contact button opens Create contact with the rider's name and number, ready to edit and save.

  1. Tap Download Remap Contacts.
  2. Tap Open on the download. If asked, allow Chrome to install apps (Only this time is fine), then tap Install. If Play Protect asks, tap Scan app, then Install.
  3. Go back to Remap Tour and tap the contact button again.
